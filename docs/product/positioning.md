# Product Positioning

Open Dice is a professional open-source dice platform for:

- D&D and tabletop players.
- Game Masters.
- Board game players.
- Educators.
- Probability experiments.
- Dice collectors.
- Makers and 3D printing users.
- Developers building dice tools.

Open Dice must avoid casino, betting, crypto, and wagering positioning. The design should feel premium, dark, elegant, tabletop-friendly, and maker-friendly.

## MVP Priorities

1. Reliable text-first dice rolling.
2. Dice notation parsing for common formulas.
3. Roll history.
4. Result-first 3D presentation.
5. Starter printable dice sources.
6. Documentation that is honest about current limits.
